# Cloud-Client

Cloud Client is a Minecraft: Java Edition launcher for Windows, currently in development.

## What it does
- Lets players sign in with their own Microsoft account (OAuth 2.0 with PKCE, in the system browser)
- Verifies that the account owns Minecraft: Java Edition
- Shows the player's profile name and skin

## Privacy
- No passwords are handled by the launcher
- Sign-in tokens are stored only on the player's own computer (Windows DPAPI)
- Accounts and credentials are never sold, shared or collected
